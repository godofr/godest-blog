andLinux (IV)

Como vengo trabajando con andLinux, el espacio inicialmente "fijado" por la distribución se me ha quedado pequeño. Ha llegado la hora de añadir un disco duro nuevo ;-)) virtual.

CONSTRUYENDO EL DISCO DURO VIRTUAL

Desde windows, como administrador (ejecutar "Símbolo del sistema" como administrador) si estamos en W7, creamos el nuevo disco virtual.

Paramos el servicio: 



C:\Program Files\andLinux\Drives>net stop andLinux

El servicio de andLinux está deteniéndose.....

El servicio de andLinux se detuvo correctamente.

Creamos el disco: N * (10243) = N GB ; siendo N=1 en este caso 



C:\Program Files\andLinux\Drives>

C:\Prog...\Drives>fsutil file createnew prue.vdi 1073741824

El archivo C:\Program Files\andLinux\Drives\prue.vdi está creado



C:\Program Files\andLinux\Drives>dir

 El volumen de la unidad C es Win7

 El número de serie del volumen es: 0EB8-1076



 Directorio de C:\Program Files\andLinux\Drives



19/03/2011  09:22    <DIR>          .

19/03/2011  09:22    <DIR>          ..

19/03/2011  09:19     4.294.967.296 base.vdi

19/03/2011  09:22     1.073.741.824 prue.vdi

13/03/2011  13:24       268.419.072 swap.vdi

               3 archivos  5.637.128.192 bytes

               2 dirs  313.645.645.824 bytes libres

Editamos el fichero, también como administrador, "settings.txt" y añadimos la nueva unidad (fijaos en la línea: cobd3=Drives\prue.vdi): 



C:\Program Files\andLinux>more settings.txt

mem=512

root=/dev/cobd0

kernel=vmlinux

cobd0=Drives\base.vdi

cobd1=Drives\swap.vdi

cobd3=Drives\prue.vdi

cofs31=.

eth0=slirp

eth1=tuntap,"TAP-Colinux",00:11:22:33:44:55

cofs0=D:\

Arrancamos el servicio: 



C:\Program Files\andLinux\Drives>net start andLinux



El servicio de andLinux se ha iniciado correctamente.

Y lo montamos en /mnt/nuevo: 



[root@andLinux mnt]# mkdir nuevo

[root@andLinux mnt]# mount /dev/cobd3 /mnt/nuevo

Como normalmente hemos de trabajar con un usuario sin privilegios de root, en mi caso "godo", hacemos que este usuario sea el propietario de la "nueva unidad": 



root@andLinux:/mnt# chown -R godo:godo nuevo/

MONTANDO LA UNIDAD AUTOMÁTICAMENTE AL INICIO

Añadimos la siguiente línea al archivo /etc/fstab (última que aparece): 



godo@andLinux:/mnt/nuevo$ more /etc/fstab

# /etc/fstab: static file system information.

#

# <file system> <mount point>   <type>  <options>               <dump>  <pass>

proc            /proc           proc    defaults                0       0

/dev/cobd0      /               ext3    defaults                1       1

/dev/cobd1      none            swap    sw                      0       0

31              /mnt/and        cofs    defaults                0       0

/dev/cofs0 /mnt/win cofs defaults,uid=godo,gid=godo,dmask=0755,fmask=0755 0 0

/dev/cobd3      /mnt/nuevo  ext3    user,exec,auto          0       0

godo@andLinux:/mnt/nuevo$
