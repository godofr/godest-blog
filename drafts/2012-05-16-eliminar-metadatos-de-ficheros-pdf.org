Pues eso.

Conseguir la herramienta e instrucciones de instalación:
http://www.pdflabs.com/docs/install-pdftk/

Para un fichero:

#+begin_example

#!/bin/bash
SAVEIFS=$IFS
IFS=$(echo -en "\n\b")

pdftk_path="/usr/bin/pdftk"  # full path to pdftk binary
pdf_infokeys="/mnt/win/tmp/pdf-infokeys"      # full path to file containing new metadata
pdf_search_path="/mnt/win/tmp"    # path to search for pdf files
pdf_temp_path="/mnt/win/tmp"               # temporary directory


  cp $1 $pdf_temp_path/temp.pdf
  $pdftk_path $pdf_temp_path/temp.pdf update_info $pdf_infokeys output $1
  rm $pdf_temp_path/temp.pdf

IFS=$SAVEIFS

#+end_example

Iterativo para todos los ficheros de un directorio:

#+begin_example

#!/bin/bash
SAVEIFS=$IFS
IFS=$(echo -en "\n\b")

pdftk_path="/usr/bin/pdftk"  # full path to pdftk binary
pdf_infokeys="~/tmp/pdf-infokeys"      # full path to file containing new metadata
pdf_search_path="/mnt/win/tmp"    # path to search for pdf files
pdf_temp_path="/tmp"               # temporary directory


for i in $( find $pdf_search_path -type f -name "*.pdf" ); do
  cp $i $pdf_temp_path/temp.pdf
  $pdftk_path $pdf_temp_path/temp.pdf update_info $pdf_infokeys output $i
  rm $pdf_temp_path/temp.pdf
done

IFS=$SAVEIFS


#+end_example
