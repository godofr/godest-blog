Añadir en /etc/hosts de andLinux y c:\windows\system32\drivers\hosts

#+begin_example

[14:12:42(root@andLinux)~]$ more /etc/hosts
...
192.168.11.150  iventalia.local
...

#+end_example

Crear el virtual host de apache:

#+begin_example

[14:10:44(root@andLinux)/etc/apache2/sites-available]$ more iventalia.local
<VirtualHost *:80>
        ServerAdmin webmaster@localhost

        DocumentRoot /var/www/iventalia.local

        ServerName iventalia.local

        #<Directory /var/www/iventalia.local/>
        #       Options Indexes FollowSymLinks MultiViews
        #       AllowOverride All
        #       Order allow,deny
        #       allow from all
        #</Directory>

        ErrorLog /var/log/apache2/error-iventalia.local.log

        # Possible values include: debug, info, notice, warn, error, crit,
        # alert, emerg.
        LogLevel warn

        CustomLog /var/log/apache2/access-iventalia.local.log combined

</VirtualHost>
[14:10:46(root@andLinux)/etc/apache2/sites-available]$

#+end_example

Habilitar el módulo de reescritura de URL:

#+begin_example

[14:06:40(root@andLinux)/etc/apache2/mods-enabled]$ ln -s ../mods-available/rewrite.load rewrite.load 

#+end_example

Descomprimir drupal en el directorio de instalación:

#+begin_example

[14:14:39(godo@andLinux)/mnt/pre]$ ll
total 20
drwxr-xr-x 10 godo godo  4096 2011-04-10 14:02 drupal-6.20

#+end_example

Crear un enlace simbólico a la carpeta descomprimida en:

#+begin_example

[14:16:05(godo@andLinux)/var/www]$ ll
total 8
-rw-r--r-- 1 root root   45 2011-04-10 11:24 index.html
lrwxrwxrwx 1 root root   20 2011-04-10 12:43 iventalia.local -> /mnt/pre/drupal-6.20

#+end_example

Para no tener problemas con drupal subimos el límite de memoria que un script puede consumir a 20M modificando la variable correspondiente que indicamos a continuación:

#+begin_example

[14:29:32(root@andLinux)/etc/php5/apache2]$ grep 16 *
php.ini:; realpath_cache_size=16k
php.ini:memory_limit = 16M      ; Maximum amount of memory a script may consume (16MB)

#+end_example
