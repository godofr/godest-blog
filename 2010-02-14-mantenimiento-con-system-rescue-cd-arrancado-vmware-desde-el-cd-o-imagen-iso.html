Mantenimiento con "System Rescue CD" [Arrancado VMware desde el CD o imagen ISO]

Para arrancar una máquina VMware desde el CD (imagen ISO montada como tal), justo cuando comienza a arrancar el sistema hay que pulsar con el ratón en la ventana para que capture el foco e instantáneamente pulsar la tecla Esc, que hará que se muestre un menú con los dispositivos disponibles para arrancar. Basta con seleccionar el número correspondiente al CD.

Así sueles probar las ISO y los Antivirus que vienen con "System Rescue CD".

Respecto a utilizar herramientas antimalware, estas estuvieron hace tiempo incluidas en "System Rescue CD", pero ahora ya no lo están. Es necesario, y quizá incluso mejor, utilizar herramientas similares propias de los fabricantes. Aquí puedes encontrar un listado con algunas de ellas: https://www.techradar.com/best/best-antivirus-rescue-disk

Echa un vistazo también a estas soluciones alternativas: http://www.linuxandubuntu.com/home/top-5-linux-system-rescue-cds

Salud!
