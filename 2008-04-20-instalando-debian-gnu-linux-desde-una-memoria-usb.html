Instalando Debian GNU/Linux desde una memoria usb

Primero particionamos el disco duro destino con gparted. Para ello arrancamos desde otra memoria usb que contiene el arranque de la distribución grml. Esta memoria usb arrancable ha sido creada con la herramienta: wget - http://hg.grml.org/grml2usb/raw-file/tip/grml2usb

Instalamos los siguientes paquetes: (root) apt-get install qemu dosfstools syslinux mtools

Bajamos los archivos de arranque (initrd.gz y vmlinuz) de: ftp://ftp.debian.org/debian/dists/testing/main/installer-i386/current/images/hd-media ¡OJO! Es importante bajar estos archivos desde la misma "rama de distribución" (stable, testing, sid) que posteriormente vamos a instalar desde el archivo .iso correspondientemente descargado.

Conectamos la memoria usb y comprobamos el dispositivo asociado por el kernel: dmesg

Comprobamos que el dispositivo es /dev/sdb1

Formateamos dicho dispositivo para partir desde cero: mkfs.vfat /dev/sdb1

Y comprobamos el espacio disponible (observar última línea): mount /mnt/usbflash

umount /mnt/usbflash

Grabamos en dicho dispositivio el sistema de arranque (root) syslinux /dev/sdb1 ¡OJO! Quizá no baste con realizar lo anterior, sino que también haya que crear un Master Boot Record (mbr) válido, lo cual se consigue con: atalaya:/home/godo# dd if=/usr/lib/syslinux/mbr.bin of=/dev/sdb

Montamos el dispositivo para comprobar que, efectivamente, hay ficheros grabados (hemos partido de una memoria usb formateada con sistema de archivos fat32): mount /mnt/usbflash (si en el /etc/fstab hemos definido este punto de montaje)

Y seguimos copiando el resto de ficheros que nos hace falta: ls -l

Y creamos el fichero de configuración del arranque con un editor de texto: vim syslinux.cfg 

default vmlinuz

append initrd=initrd.gz ramdisk_size=10240 root=/dev/rd/0 devfs=mount,dall rw DEBCONF_PRIORITY=medium

La memoria usb queda con el siguiente contenido: ls -l

[12:43:28(godo@atalaya)/mnt/usbflash]> ll total 663392 -rwxr-xr-x 1 godo godo 674988032 2008-04-20 12:39 debian-testing-i386-kde-CD-1.iso -rwxr-xr-x 1 godo godo 3207145 2008-04-20 12:33 initrd.gz -r-xr-xr-x 1 godo godo 9932 2008-04-20 12:28 ldlinux.sys -rwxr-xr-x 1 godo godo 118 2008-04-20 12:43 syslinux.cfg -rwxr-xr-x 1 godo godo 1099704 2008-04-20 12:33 vmlinuz [12:43:30(godo@atalaya)/mnt/usbflash]>

Desmontamos dicha memoria umount /mnt/usbflash

Comprobamos que el sistema de arranque hace su función. Utilizamos qemu para ello. qemu -m 512 -hda /dev/sdb1 Ver captura de pantalla.
